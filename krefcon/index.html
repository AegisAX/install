내려받을 때 “신뢰할 수 있는지 확인합니다” 경고가 나오면 — 자세히 보기 → 창 아래 삭제 오른쪽의 ∨ → 그래도 계속. 스토어를 거치지 않고 배포하는 프로그램이라 게시자가 “알 수 없음”으로 표시됩니다.

Windows 10 · 11

버전 1.18.3

내려받아 설치하기

내려받은 K-REFCON-x64-v1.18.3.exe 를 두 번 클릭하면 설치가 시작됩니다. 받는 도중과 설치 중에 아래 창들이 나오면 그대로 진행하시면 됩니다.

  1. “열기 전에 K-REFCON-x64-v1.18.3.exe을(를) 신뢰할 수 있는지 확인합니다” (다운로드 중 브라우저 경고) → 자세히 보기 → 창 아래 삭제 버튼 오른쪽의 ∨ → 그래도 계속
    내려받은 사람이 적은 파일이라 Microsoft Defender SmartScreen이 한 번 확인하는 단계입니다. 게시자: 알 수 없음으로 나오는 것은 코드 서명 인증서를 쓰지 않기 때문이며, 파일이 지워진 것처럼 보여도 이 단계를 마치면 다운로드 폴더에 남습니다. (Chrome·다른 브라우저에서는 다운로드 항목의 ⋮ → 계속 또는 파일 유지)
  2. “Windows의 PC 보호” 창 → 추가 정보 → 실행
    스토어를 거치지 않고 배포하는 프로그램이라 나오는 안내입니다.
  3. “이 앱이 디바이스를 변경할 수 있도록…” 창 → 예
  4. “K-REFCON을(를) 설치하시겠습니까?” 창 → 설치

설치가 끝나면 앱이 바로 실행됩니다. 이후 업데이트는 자동이라 이 페이지를 다시 찾을 필요가 없습니다.

설치 후 알아두실 것

  1. 창을 닫아도 꺼지지 않습니다. 알림 영역(^)의 눈송이 아이콘으로 남아 계속 감시합니다. 완전히 끄려면 그 아이콘을 오른쪽 클릭 → 종료.
  2. PC를 켜면 자동으로 실행됩니다.
  3. 드로어(☰) → 백그라운드 알람 설정 → 테스트 알림 보내기 로 알람이 울리는지 한 번 확인해 보세요.
  4. ⚠️ PC가 절전에 들어가면 감시가 멈춥니다. 상황판으로 쓰신다면 같은 화면에서 절전 방지를 켜 두세요.

macOS 10.15 이상

버전 1.18.4

내려받아 설치하기

내려받은 K-REFCON-Universal-v1.18.4.dmg 를 두 번 클릭하면 창이 하나 열립니다.

  1. 창 안의 K-REFCON 아이콘을 옆의 “응용 프로그램” 폴더로 끌어다 놓습니다. (이게 설치입니다)
  2. 설치가 끝나면 Launchpad 또는 응용 프로그램 폴더에서 K-REFCON 을 실행합니다.
  3. 처음 실행할 때 “인터넷에서 다운로드한 응용 프로그램입니다. 열겠습니까?” 창이 나오면 열기 를 누릅니다. (한 번만 나옵니다)
    Apple 공증(notarization)을 받은 앱이라 그 외의 경고는 나오지 않습니다.
  4. 처음 실행 시 알림 허용 을 물으면 허용 을 눌러 주세요. 알람이 화면에 뜨려면 필요합니다.

바탕화면에 남은 흰색 디스크 아이콘은 “추출”(꺼내기) 해도 됩니다.

설치 후 알아두실 것

  1. 창을 닫아도 꺼지지 않습니다. 화면 위쪽 메뉴 막대의 눈송이 아이콘으로 남아 계속 감시합니다. 창을 다시 열려면 그 아이콘을 누르거나 Dock 아이콘을 클릭하세요. 완전히 끄려면 메뉴 막대 아이콘 → 종료.
  2. Mac을 켜면 자동으로 시작하게 하려면 앱 안에서 드로어(☰) → 백그라운드 알람 설정 → 부팅 시 자동 시작 을 켜세요.
  3. 같은 화면의 테스트 알림 보내기 로 알람이 울리는지 한 번 확인해 보세요.
  4. ⚠️ Mac이 잠자기에 들어가면 감시가 멈춥니다. 상황판으로 쓰신다면 같은 화면에서 절전 방지 를 켜 두세요. 켜지면 “현재 절전 차단 중” 이라고 표시됩니다.
  5. 업데이트: 새 버전이 나오면 앱이 알려줍니다. 드로어 아래쪽 업데이트 확인 으로 직접 확인할 수도 있습니다.
