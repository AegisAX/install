㈜케이리퍼콘

Windows 10 · 11

버전 1.16.0

창을 닫아도 트레이에 남아 계속 감시합니다. 설치 후에는 업데이트가 자동으로 이루어집니다.

  1. 아래 두 파일을 같은 폴더에 내려받습니다.
  2. PowerShell을 관리자 권한으로 열고, 내려받은 폴더에서 실행합니다:
    Set-ExecutionPolicy -Scope Process Bypass -Force
    .\krefcon-setup.ps1
  3. 설치 창이 열리면 [설치]를 누릅니다.
1. 설치 스크립트 내려받기 2. 인증서 내려받기 (krefcon.cer)

왜 인증서가 필요한가요? 이 앱은 Microsoft 스토어를 거치지 않고 배포되므로, PC가 설치 파일의 서명을 신뢰하도록 최초 1회 등록해야 합니다. 스크립트가 이 과정을 대신 해줍니다. 이후 업데이트에는 다시 필요하지 않습니다.

설치 후 확인

처음 한 번만

  1. 창을 닫아도 알림 영역(^)에 눈송이 아이콘이 남아 있는지 — 감시가 계속된다는 뜻입니다.
  2. 설정 → 앱 → 시작 프로그램에서 K-REFCON이 켜져 있는지 — PC를 켜면 자동으로 감시를 시작합니다.
  3. 드로어(☰) → 백그라운드 알람 설정 → 테스트 알림 보내기로 알람이 실제로 울리는지.

⚠️ PC가 절전에 들어가면 폴링이 멈춰 알람도 울리지 않습니다. 상황판으로 쓰신다면 같은 화면에서 절전 방지를 켜 두세요.
